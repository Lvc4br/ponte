# Segurança e divulgação responsável

Não publique credenciais, arquivos SQL internos, bases SQLite reais, planilhas corporativas ou informações pessoais em issues ou pull requests.

Para comunicar uma possível vulnerabilidade, utilize os recursos privados de segurança do GitHub disponíveis na página do repositório. Inclua passos para reproduzir sem anexar dados confidenciais.

O aplicativo processa arquivos SQL locais fornecidos pelo usuário. Execute somente scripts de origem confiável. O SQL é executado para reconstruir a base SQLite local.
