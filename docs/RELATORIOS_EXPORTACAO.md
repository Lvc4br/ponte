# Relatórios e exportações

A página **Relatórios** exporta o recorte atualmente exibido em **Análise de engenharia**. Os filtros e a pesquisa aplicados nessa tela definem quais registros entram nos arquivos.

## Formatos disponíveis

- XLSX: planilha com uma aba de resumo, gráfico incorporado e aba de dados filtrados.
- DOCX: documento editável com identificação do projeto/conjunto, resumo, gráfico e tabela.
- PPTX: apresentação editável com capa, resumo gráfico e tabelas divididas em slides.
- PDF: relatório paginado com resumo, gráfico e tabela.

## Gráficos

A primeira versão oferece pizza/rosca, barras, linhas e radar. O usuário escolhe uma coluna para agrupar os dados e uma coluna numérica para agregar por soma.

Os gráficos são descritivos. Eles não constituem avaliação de segurança, diagnóstico estrutural nem validação de fórmulas ou indicadores de engenharia.

## Limites

- A exportação utiliza apenas os registros fornecidos pela tela de análise; não altera a base de dados nem os arquivos de origem.
- A agregação do gráfico é uma soma por categoria. Para indicadores cuja interpretação exija média, mediana, normalização ou outra regra, a metodologia deve ser definida antes de uso técnico.
- DOCX, PPTX e XLSX são editáveis; o PDF é destinado à leitura e compartilhamento.
